# Example: Game Demo

This example describes how DemoAgent might structure a demo for a game, interactive prototype, or simulation.

## Example Goal

Show the core loop: launch the game, perform a meaningful player action, trigger feedback, and reach a recognizable outcome.

## Example Storyboard

| Step | Action | Expected Result | Evidence |
| --- | --- | --- | --- |
| 1 | Start the game. | The title, menu, or initial scene appears. | Opening screenshot |
| 2 | Begin a session. | Gameplay state becomes interactive. | Video segment or screenshot |
| 3 | Perform the core action. | The game responds visibly. | Action screenshot or recording |
| 4 | Reach an outcome. | Score, win/loss state, level transition, or changed world state is visible. | Final screenshot |

## Example Verification Notes

- Capture visual evidence that the game is interactive, not just loaded.
- Note performance issues, missing assets, input problems, or blank canvases.
- If recording is unavailable, include keyframes and a written action trace.
