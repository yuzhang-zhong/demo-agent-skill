# Example: React App Demo

This example describes how DemoAgent might structure a demo for a React application.

## Example Goal

Show that a user can open the app, complete the primary UI flow, and see the expected result on screen.

## Example Storyboard

| Step | Action | Expected Result | Evidence |
| --- | --- | --- | --- |
| 1 | Start the dev server. | App is available at a local URL. | Terminal log |
| 2 | Open the home screen. | The initial UI renders without errors. | Opening screenshot |
| 3 | Perform the main interaction. | The UI updates to show the result. | Interaction screenshot or video segment |
| 4 | Confirm the final state. | The result remains visible and understandable. | Final screenshot |

## Example Verification Notes

- Successful steps should be supported by screenshots, browser state, or logs.
- Failed rendering, missing dependencies, or console errors should be reported.
- If browser recording is unavailable, include screenshots and a written trace.
