# Agent Guidance

This repository defines **DemoAgent**, an agent skill for producing reproducible software demo artifacts.

## Repository Intent

Keep this project focused on skill instructions, workflow design, templates, and examples. Avoid turning it into a large script collection unless repeated real-world use shows that automation is needed.

## Editing Guidelines

- Write all documentation in English.
- Keep `SKILL.md` as the primary entry point.
- Keep workflow files practical and agent-oriented.
- Keep templates reusable across project types.
- Add examples that show intent without becoming heavyweight sample applications.
- Separate demonstrated behavior from assumptions or aspirations.

## Quality Bar

Before considering a change complete, check that:

- The skill still explains when to use DemoAgent.
- The workflow still follows project understanding, goal clarification, planning, execution, evidence capture, verification, and artifact composition.
- Honesty and reproducibility rules remain visible and explicit.
- New files have clear names and a clear purpose.
- Example artifacts do not claim that unverified behavior was actually demonstrated.

## Future Extension Ideas

Good future additions may include:

- Browser recording adapters.
- CLI trace collectors.
- Project-type-specific demo checklists.
- Example output packages from real projects.
- Lightweight validation scripts for demo artifact completeness.
